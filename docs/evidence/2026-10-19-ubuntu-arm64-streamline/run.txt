Streamlined setup of Companion OS (Ubuntu edition) on arm64, three images, one run each, in the repository's arm64 VM harness. The records behind KI-30 (docs/architecture/known-issues-and-decisions.md).
Evidence label: tested in a virtual machine (QEMU 11.1.2, HVF, one Apple-silicon Mac); not real hardware; one run of each image; amd64 not built. 2026-10-19 local time; every time below is UTC of 2026-10-20.

Images (all built from a clean `git archive` tree in a native arm64 ubuntu:26.04 container, then verify-iso.sh with VERIFY_BASE_ISO and VERIFY_REQUIRE_CANON=1)

         the boot menu's automatic entry chosen with Down, Enter; after the install the disk started alone. Facts were read by the scripts in guest-scripts/ (read-only), fetched by the
         guest from a loopback server on the host and posted back (curl, or wget where curl is missing). Frames and videos are not in the repository.
