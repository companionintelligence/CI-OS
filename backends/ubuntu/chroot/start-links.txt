# Companion links of the Ubuntu image: one line per link, fields separated by "|":
#   id | name | url | comment | icon | on the desktop of a new user (yes or no)
#
# customize-chroot.sh turns every line into an application-menu entry (/usr/share/applications/<id>.desktop, searchable and
# pinnable) and every "yes" line into a shortcut on the desktop of each new user (/etc/skel/Desktop). The dock list
# (dock-favorites.txt) can pin any of them by id. backends/ubuntu/lib/start-links.sh checks this file before anything is written.
#
# Every URL below answered HTTP 200 when it was fetched on 2026-10-19. They are the links the ci.computer site itself
# shows (docs.ci.computer, hub.ci.computer, the support page and the community invite); none is guessed.
# The icons are names from the Yaru icon theme that the image ships.
